WordPress Demo Import Failed? 8 Safe Steps to Fix It

A stuck progress bar, missing images or an error before any pages appear are three different problems. Here's how to find which one you have, and fix it without losing content.

Daniel OrtizSenior support engineer
Nov 06, 2026 10 min read Updated for WordPress 6.7

WordPress demo import failed? Stop before you press “Import” again. Repeating a broken import often creates duplicate pages, menus and media that are painful to clean up later. The most useful next step depends on what actually went wrong.

This guide walks you through eight checks our support team uses every day. They work for theme demo importers, the WordPress XML importer and Elementor kit imports.

Key takeaways

  • Most failed imports are caused by low PHP limits on shared hosting.
  • Always install the theme's required plugins before importing.
  • Back up first, and never re-run a full import on a live site.

Before you start: the right first check

Write down the exact error message, the importer you used, the demo you selected and the time of the attempt. Then look at Pages, Media and Menus to see what already exists. A failed request doesn't necessarily mean nothing was imported.

Working on a live business site?Use a staging copy whenever possible, and take a full backup of files and database before changing plugins or server settings.

1. Identify the importer and the correct package

Themes ship more than one file. Uploading the full download ZIP instead of the installable theme ZIP is the single most common mistake we see.

  • Upload builta.zip (the theme), not builta-package.zip (the full download).
  • Check that the demo you chose matches your theme version.
  • Use the importer recommended in the theme documentation.

2. Install the required plugins first

Demo content references widgets from Elementor, Contact Form 7 and the theme's core plugin. If those plugins are missing, pages import empty or the importer stops halfway.

  1. Go to Appearance → Install Plugins.
  2. Install and activate every plugin marked Required.
  3. Refresh the importer page, then run the import once.

3. Check your server limits

Shared hosting often ships with limits that are too low for a full demo. Check them under Tools → Site Health → Info → Server.

SettingMinimumRecommended
memory_limit256M512M
max_execution_time120300
upload_max_filesize32M64M
PHP version7.48.2+

If you can't change these yourself, add the lines below to wp-config.php or ask your host:

// wp-config.php, above "That's all, stop editing!"
define( 'WP_MEMORY_LIMIT', '512M' );
set_time_limit( 300 );

4. Fix missing images and media

If pages appear but images are grey boxes, the importer couldn't download media from the demo server. This is usually caused by a firewall or by allow_url_fopen being disabled.

5. Read the error logs

Enable debugging to see the real cause instead of a generic “Import failed” message. Add define( 'WP_DEBUG_LOG', true ); and check wp-content/debug.log right after the next attempt.

“Nine out of ten import tickets we receive are solved by raising the memory limit and activating the required plugins.”Daniel Ortiz, Senior Support Engineer

6. Recover from a partial import

If some content imported, don't run the full import again. Remove the duplicates first, or reset the site with a plugin like WP Reset on a fresh install only, then import once with the fixes above in place.

7. Try a manual or selective import

Most importers let you import content, widgets and customizer settings separately. Importing step by step uses less memory and makes it obvious which part is failing.

Which import method to use, depending on what went wrong.
MethodBest forMemory useTime
Full one-click importFresh installs on good hostingHigh2–5 min
Selective importShared hosting, timeoutsMedium5–10 min
Manual XML + widgetsRepeated failures, strict serversLow15–20 min
Elementor kit onlyAdding single pages or templatesLow1–2 min

8. Verify the site after import

  • Set the homepage under Settings → Reading.
  • Assign the main menu under Appearance → Menus.
  • Regenerate Elementor CSS under Elementor → Tools.
  • Save permalinks once to refresh rewrite rules.
Done!Your site should now match the demo. If anything still looks off, our support team can take a look. Just open a ticket with your error message.

Frequently asked questions

Will importing a demo delete my existing content?

No. Importers add content; they don't delete it. But they can create duplicates, which is why a backup is important.

How long should a demo import take?

Between two and ten minutes depending on your hosting. If it runs longer than 15 minutes, it has most likely timed out.
